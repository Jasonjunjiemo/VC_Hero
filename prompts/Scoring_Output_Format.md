# 评分输出格式要求

请严格按以下 JSON 格式输出评分结果，不要输出 JSON 以外的任何内容：

```json
{
  "scores": {
    "task_understanding": 0,
    "signal_identification": 0,
    "prioritization": 0,
    "judgment_update": 0,
    "decision_expression": 0
  },
  "total": 0,
  "grade": "A",
  "feedback": "500-1000 字的综合反馈全文"
}
```

字段说明：

- `scores`：五项能力各自的分数（0-100 整数），对应评分规则中的：任务理解与目标拆解、关键信号识别、优先级与取舍能力、面对新信息的判断调整、最终决策与表达能力。
- `total`：五项分数的平均值（可保留一位小数）。
- `grade`：A / B / C / D / E 之一，与总分区间对应（A: 85-100，B: 75-84，C: 60-74，D: 40-59，E: 0-39）。
- `feedback`：严格按评分规则第七节"反馈应该怎么写"的结构撰写，包含总体判断、最明显的优势、最核心的问题、为什么这个问题重要、下一步训练建议五个部分，500-1000 字，措辞严格、专业、具体，直接指出问题，不用情绪价值式措辞。反馈中可以使用换行符分段。
